아낀시간 영수증

말로 쓴 업무 설명 → AI가 업무·건당 분 구조화 → 메신저 기록 붙여넣기 → AI가 자동 분류 → 주간 영수증. 처리마다 「AI」 또는 「규칙」 표기가 붙습니다.
시연용 합성(비식별) 글이 채워져 있습니다. 실제 사업장 측정값이 아닙니다. AI 단계는 입력한 글을 이 컴퓨터의 시연 서버를 거쳐 모델에 보냅니다. 이름·전화번호 같은 개인정보는 넣지 마십시오.

1. 5분 진단 — 하루 업무를 말로 쓰기

기준표에 건수를 직접 입력하기

2. AI 도구 하나 켜고, 실행 기록 붙이기

메신저·도구 기록을 형식 없이 그대로 붙여 넣으십시오. 날짜가 있으면 쓰고, 없으면 아래 시작일로 계산합니다. 줄마다 업무와 성공/실패를 AI가 가립니다.

4. 실사업장 1곳 실기록 영수증 — 지도사 결과보고서 칸 출력

위 1~3은 합성(비식별) 시연입니다. 이 4번만 제안자 본인 1인 사업체가 AI와 실제로 운영한 작업 기록(시작·종료 시각)을 종류별로 센 실측 집계입니다. 실측은 건수와 소요 분뿐이고, 사람이 직접 했을 때의 분은 측정하지 않아 절감 시간·원 환산은 내지 않습니다. 내용·이름·금액은 집계에 없습니다.
