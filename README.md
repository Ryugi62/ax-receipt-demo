# 아낀시간 영수증 시연판

2026년 하반기 AI 경진대회 학생 부문 출품작의 시연판(v3)입니다. 의존 라이브러리 0. 두 가지로 쓸 수 있습니다.

- AI 켜기: `GEMINI_API_KEY=<본인 키> node server.js` 후 http://127.0.0.1:8787 접속. AI 단계 2개가 실제 모델(gemini-3.5-flash-lite)을 호출합니다. 키는 환경 변수로만 읽고 파일·화면·로그에 쓰지 않습니다. 입력한 글은 이 컴퓨터의 서버를 거쳐 Google 모델 API로 갑니다(개인정보 입력 금지).
- AI 없이: `index.html`을 그냥 열면 전부 규칙으로 동작하고 화면에 「규칙」이 표기됩니다. 모델 호출이 실패해도 영수증은 나옵니다.

- 진단(가): 사장님이 말하듯 쓴 하루 업무 설명을 모델이 업무 목록·주당 건수·건당 분(수작업/AI 후 확인)·AI 도구 후보로 구조화합니다. 화면에 「AI(모델명)」 또는 「규칙」이 붙습니다. 업종과 건수를 직접 적는 기준표 진단도 남아 있습니다.
- 영수증(나): 메신저·도구 기록을 형식 없이 붙이면 모델이 줄마다 업무 종류와 성공/실패를 분류합니다. 날짜가 있으면 쓰고 없으면 시작일로 계산합니다. 한 줄씩(`2026-10-05 12:03 예약 문의 자동답장 성공`) 붙이던 v1 형식도 됩니다. 아낀 시간·환산액과 「진단 추정 대 영수증 집계」 표가 나옵니다.
- 시연 데이터는 합성(비식별)이며 실제 사업장 측정값이 아닙니다. 환산은 보수 환산(시급만 곱함)입니다.
- 지표 정의: 「아낀 시간(분) = 성공 실행 건수 × (수작업 건당 분 − AI 처리 후 확인 분)」, 「환산액(원) = 아낀 시간(분) ÷ 60 × 시급」. 분모 60, 단위 분·원, 비교 기준선은 사장님이 진단 때 적은 추정.
- 시험: `node --test test/core.test.js test/ai.test.js test/measured.test.js` (외부 호출 0, 모델 응답은 가짜 함수로 대체)
- 측정표 재현: `GEMINI_API_KEY=<키> node bench.js` → `bench/results-<날짜>.json` (표본 `bench/classify.jsonl`·`bench/diagnose.jsonl`, 합성·작성자 정답, 약 6분, 무료 등급 한도 때문에 호출 간격 4.5초)
- 명령줄: `node cli.js diagnose data/sample-diagnosis.json`, `node cli.js receipt data/sample-diagnosis.json data/sample-log-synthetic.txt`
- 기준표의 건당 분 값은 작성자 가정값(출처 없음)이고, AI 진단의 건당 분은 모델이 설명에서 추정한 값입니다(둘 다 실측 아님). 사장님 본인 값으로 바꿔 쓰십시오.

## v3: 실사업장 1곳 실기록 영수증 · 지도사 결과보고서 칸
- 화면 4번 「실기록 영수증 보기」: 제안자 본인 1인 사업체가 AI와 운영한 작업 기록(시작·종료 시각)을 업무 종류별로 센 실측 집계(`data/measured-aggregate.json`)를 영수증으로 보이고, 같은 내용을 지도사 결과보고서 칸(문제·조치·효과·근거) 문단으로 냅니다. 실측은 건수와 소요 분뿐이며, 사람이 직접 했을 때의 분은 측정하지 않아 절감 시간·원 환산은 내지 않습니다(미측정). 앞 1~3의 합성 시연 숫자(149줄·490분·84,280원)와 섞이지 않습니다.
- 집계 방법 재현: `python3 tools/extract_lanes.py <작업 기록.jsonl> data/measured-aggregate.json <시작일> <종료일>` — 설명 글은 읽어서 업무 종류만 정하고 출력하지 않습니다. 시험: `python3 tools/test_extract.py`.
- 합성 사례는 하나로 통일: 합성 149줄 → 집계 140건 → 490분(8.17시간) → 84,280원. 첫 화면에 이미 채워져 있습니다(「형식 없는 예시 13줄」 단추로 AI 분류용 다른 말투 예시도 볼 수 있습니다).
- 첫 영수증까지: 사람이 처음 써서 걸린 시간은 미측정(사람 표본 0). 키·서버 없이 index.html만 열면 1단계·클릭 0회로 영수증이 나오고, 본인 기록을 붙여 넣으면 3단계·클릭 1회입니다.
